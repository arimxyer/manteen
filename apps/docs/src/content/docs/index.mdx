Manteen has two public tools:

- **`manteen-kit`** compiles a Mantine-shaped authoring catalog into portable registry JSON.
- **`manteen`** initializes applications and safely installs, tracks, diffs, and updates that source.

Mantine remains an ordinary npm dependency. Registries hold the composed layer your project is
expected to own and edit.
