# Manteen kit 0.3 and client 0.9 release handoff

[Documentation map](../project-context.md) · [Release receipts](README.md)

Status: complete and public on 2026-09-01. The kit and client packages, hosted portability
matrix, signed tags, npm provenance, and fresh public consumer are accepted. This release did not
deploy the Fumadocs application or `public/r/`; the repository has no workflow that publishes
either artifact.

## Release boundary

PR [#42](https://github.com/arimxyer/manteen/pull/42) merged the release train at
`044e3836327ce3be97cdc536c9fdd30727749f49`. The signed annotated tags
`manteen-kit-v0.3.0` and `manteen-v0.9.0` both point to that merge commit, and GitHub reports both
SSH signatures as verified.

This clean-break release moves the kit and client command envelopes directly to schema v2. It
also publishes:

- exact reviewed rerun actions and dependency-command previews;
- receipt-aware registry and script-discovered verification configuration commands;
- the foreground `manteen-kit dev` last-good registry server; and
- author-profile v2 ownership for Styles API, props, and usage evidence.

The client declares `manteen-kit@^0.3.0`, so the kit was tagged, published, and independently
accepted before the client tag was pushed.

## Candidate and hosted verification

Before the release commit, the repository passed 427 source tests, TypeScript and Fumadocs
checking, Biome linting, every mechanical guard, the 22-item registry build, both package builds,
145 client built-Node e2e cases with one intentional opt-in skip, three kit built-Node e2e cases,
and the Fumadocs production build. Both exact-tag release guards also passed.

Hosted CI found two portability defects in the kit dev e2e fixture before accepting the release:

- [run 33459022331](https://github.com/arimxyer/manteen/actions/runs/33459022331) exposed the
  `/var` to `/private/var` temporary-directory symlink on macOS; the fixture now canonicalizes its
  temporary root while production symlink refusal remains intact.
- [run 33459156092](https://github.com/arimxyer/manteen/actions/runs/33459156092) proved that
  Node's Windows `child.kill("SIGINT")` forcibly terminates a process rather than synthesizing a
  console Ctrl-C; the fixture preserves the POSIX stopped-event assertion and tests Windows'
  actual termination semantics.

PR #42 [run 33459414344](https://github.com/arimxyer/manteen/actions/runs/33459414344) then passed
the source/type/lint/guard gate; Node 20.11 scaffold and consumer proof; built Node 22.12 on Linux,
macOS, and both Windows shards; Node 24 and 26 on Linux; packed npm, pnpm, Yarn, and Bun consumers
on Linux; packed npm on Windows; and the required aggregate CI gate.
