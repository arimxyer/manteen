# Manteen kit 0.3.1 and client 0.9.1 release handoff

[Documentation map](../project-context.md) · [Release receipts](README.md)

Status: complete and public on 2026-09-01. The kit and client packages, hosted portability
matrix, signed tags, npm provenance, and fresh public consumer are accepted. This release did not
deploy the Fumadocs application or `public/r/`; the repository has no workflow that publishes
either artifact.

## Release boundary

PR [#44](https://github.com/arimxyer/manteen/pull/44) merged the release train at
`7a0ec896b8540a741278e19b16d0b64212211e1e`. The signed annotated tags
`manteen-kit-v0.3.1` and `manteen-v0.9.1` both point to that merge commit and verify against the
maintainer's configured SSH signing key.

This release publishes the post-0.9 reliability and dashboard-evaluation tranche. The kit adds
complete registered scaffolds, author verification, reconnect previews, package identity, strict
alias-like target refusal, and wrapper-safe terminal shutdown events. The client adds receipt-first
offline inventory, registry reconnect, explicit verification and rollback scope, truthful update
failures and no-op outcomes, dependency-safe machine stdout, bounded corrupt-receipt errors, and
strict alias-like target refusal.

The client declares `manteen-kit@^0.3.1`, so the kit was tagged, published, and independently
accepted before the client tag was pushed.

## Candidate and hosted verification

The release candidate passed 454 source tests; TypeScript and Fumadocs checking; Biome linting;
every mechanical guard; the 22-item registry build; both package builds; 155 client built-Node e2e
cases with one intentional opt-in skip; six kit built-Node e2e cases; the Fumadocs production build;
and both exact-tag packed-surface guards.

Initial PR [run 33525839336](https://github.com/arimxyer/manteen/actions/runs/33525839336)
exposed two invalid assumptions in the new npm-wrapper acceptance fixture: its hand-written binary
shim was not portable to npm 10.2.4, and it sent SIGINT only to the npm wrapper rather than the
foreground terminal process group. The fixture now models a real installed local package, resolves
offline, and signals the detached foreground group. Exact Node 20.11.0 plus npm 10.2.4 passed
locally before the repair was pushed.

PR-native [run 33526485900](https://github.com/arimxyer/manteen/actions/runs/33526485900)
then passed the source/site/guard gate; Node 20.11 scaffold and consumer proof; built Node 22.12 on
Linux, macOS, and both Windows shards; Node 24 and 26 on Linux; packed npm, pnpm, Yarn, and Bun
consumers on Linux; packed npm on Windows; and the required aggregate CI gate. Manual exact-head
[run 33526511909](https://github.com/arimxyer/manteen/actions/runs/33526511909) independently passed
the same matrix.
