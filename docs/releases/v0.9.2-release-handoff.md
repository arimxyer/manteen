# Manteen kit 0.3.2 and client 0.9.2 release handoff

[Documentation map](../project-context.md) · [Release receipts](README.md)

Status: complete and public on 2026-09-01. The kit and client packages, hosted portability
matrix, signed tags, npm provenance, and fresh public consumer are accepted. This release did not
deploy the Fumadocs application or `public/r/`; the repository has no workflow that publishes
either artifact.

## Release boundary

PR [#46](https://github.com/arimxyer/manteen/pull/46) merged the release train at
`48f2d0fc79769a16772eec47eb47af2b0efd93ab`. The signed annotated tags
`manteen-kit-v0.3.2` and `manteen-v0.9.2` both point to that merge commit and verify against the
maintainer's configured SSH signing key.

This release closes three regressions exposed by the clean-room dashboard evaluations. Registered
Styles API scaffolds now add their generated test to author verification, exact no-work updates
return without entering apply or project verification, and npm-owned interactive kit dev sessions
emit their final stopped event and exit when Ctrl-C is typed in a real PTY. It also freezes the
two-level `build --check --json` success contract in tests and packaged guidance.

The client declares `manteen-kit@^0.3.2`, so the kit was tagged, published, and independently
accepted before the client tag was pushed.
