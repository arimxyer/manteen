# Manteen kit 0.3.3 and client 0.9.4 release handoff

[Documentation map](../project-context.md) · [Release receipts](README.md)

Status: complete and public on 2026-09-01. The kit and client packages, hosted portability
matrix, signed tags, npm provenance, and fresh public consumer are accepted. This release did not
deploy the Fumadocs application or `public/r/`; the repository has no workflow that publishes
either artifact.

## Release boundary

PR [#50](https://github.com/arimxyer/manteen/pull/50) merged the release train at
`bc17853eabfa459153b7c134a934ff3dc0b8b994`. The signed annotated tags
`manteen-kit-v0.3.3` and `manteen-v0.9.4` both point to that merge commit and verify against the
maintainer's configured SSH signing key.

This release closes three lower-severity packaged-consumer findings from a clean-room dashboard
evaluation. Package README references now resolve on the published surface, agent-guide release
identity comes from the client manifest, and Vite init preserves the generated application's
import punctuation and clean JSX indentation. The release guard now rejects package-escaping
README links.

The client declares `manteen-kit@^0.3.3`, so the kit was tagged, published, and independently
accepted before the client tag was pushed.
