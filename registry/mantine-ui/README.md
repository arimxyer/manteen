# Mantine UI-derived registry content

The components in this directory are adapted from
[`mantinedev/ui.mantine.dev`](https://github.com/mantinedev/ui.mantine.dev) at commit
`ffbf61c559f374a7ea28fcf00355e84dcbe9a908` (observed 2026-07-30).

Mantine UI is MIT-licensed. The upstream license is preserved verbatim in `LICENSE`, and every
derived registry item depends on the shared `mantine-ui-license` item so the notice is installed at
`LICENSES/MANTINE-UI.txt` with the copied source.

This is a curated port rather than a mirror. Preview-only Storybook files, repository-local tests
and `attributes.json` are not shipped. Component APIs may be made prop-driven, demo data removed,
filenames normalized and upstream-only imports replaced, while the visual and behavioral design
remains attributable to the pinned source.
